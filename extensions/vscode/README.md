# Trainz VSCode Extension

VSCode extension for the Trainz Game Script (GS) and AcsText languages, providing language server protocol (LSP) support.

## Features

- Syntax highlighting for GS (`.gs`) and AcsText (`.txt`) files
- Semantic token support
- Language Server Protocol integration

## Configuration

The extension can be configured via VSCode settings:

- `trainz-language-server.server-bin`: Path to the `trainz-language-server` executable.
- `trainz-language-server.validation-path`: Path to the Trainz Validation files.
- `trainz-language-server.search-paths`: Path to additional Trainz GS include files.

## Requirements

- Requires the `trainz-language-server` executable to be available on your system.
